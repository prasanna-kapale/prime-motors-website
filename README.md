# Prime Motors Website

## Overview
A modern responsive automotive business website developed for a real-world client project through Connec8.

This project focuses on creating a clean digital presence for an automotive business while integrating scalable system architecture and modern frontend workflows.

---

## Features
- Responsive modern UI
- Business-focused landing pages
- Admin panel pages
- Invoice & management sections
- Mobile-friendly design
- Structured frontend architecture
- Supabase integration
- Vite-based project setup
